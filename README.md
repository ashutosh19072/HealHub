# HealHub

HealHub is a Medicine Availability and Nearby Pharmacy Finder System.

Technologies Used:
- Java Servlet
- JSP
- JDBC
- MySQL
- Apache Tomcat
- HTML/CSS/JavaScript
- Google Maps API

Setup Instructions:

1. Create MySQL database:

CREATE DATABASE healhub;

2. Import:

database/healhub.sql

3. Configure DBConnector.java

4. Run project on Apache Tomcat

Features:
- User Authentication
- Medicine Search
- Pharmacy Registration
- Nearby Pharmacy Finder
- Stock Management
- Admin Dashboard
